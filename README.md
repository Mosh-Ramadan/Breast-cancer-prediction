# Breast Cancer Prediction App 🎗️

This Streamlit web app predicts whether a breast tumor is **Benign** or **Malignant** using an **Artificial Neural Network (ANN)** model.

## 🚀 Features
- Interactive UI with sliders to enter feature values
- Real-time model predictions
- Visualization of dataset and model accuracy

## 🛠 Installation & Usage
```bash
# Clone the repository
git clone https://github.com/your-username/breast-cancer-prediction.git

# Install dependencies
pip install -r requirements.txt

# Run the Streamlit app
streamlit run app.py
